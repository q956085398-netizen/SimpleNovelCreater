# 发稿前自查清单

> 每章发稿前过一遍。前两组来自拆书实践（[拆书示例](../01-拆书/拆书示例-护送未亡人.md) 里反复出现的问题），第三组来自桥段结构。60 秒能过完，别跳过——清单的存在就是替疲倦状态的你把关。

## 一、活人气（防 AI 白开水）

- [ ] 本章主角有心理活动吗？（不是流水账式的平静，要有欲望、吐槽、忐忑或盘算——拆书笔记：「主角心理活动太少太平」= 白开水）
- [ ] 主角「有勇有谋有善心」至少体现一项？
- [ ] 主角正视自己的欲望了吗？（反面案例：明明羡慕嘴上说不羡慕——「主角可以不强，但不能没志气」）
- [ ] 危机/强敌面前，主角有一丝真实反应（忐忑）再选择硬刚，而不是无情绪碾压？

## 二、人物与合理性

- [ ] 本章出场人物的行为，都在各自小传的「一致性红线」内？（防 OOC、防临时加设定）
- [ ] 涉及实力对比/组织出手的内容，和前面的展示对得上账？（读者记得住前后矛盾）
- [ ] 有没有让主角显得像小丑的对比失误？（反面案例：配角先说不绕路、见高手后又改口，反衬主角无能）
- [ ] 尺度/筛选读者的桥段，是我有意写的吗？（无意写出来的，删；有意写的，确认代价已登记）

## 三、结构与节奏（对照[桥段四章结构](桥段四章结构.md)）

- [ ] 本章在桥段里的功能（代入/拉期待/兑现/承上启下）明确，且千字分配符合比例（第1章5:5、第2章9:1）？
- [ ] 兑现章爽点写透了吗？没有偷偷塞新钩子？
- [ ] 善后章的内容是否全部服务于「收尾上一桥段 / 开启下一桥段」？（其他内容都会影响追读）
- [ ] 本章结尾有钩子吗？（除兑现章外都需要）
- [ ] 本章推进了大纲上的哪个单元？（答不上来 = 剧情在空转）

## 频率建议

- 每章：全文过一遍（60 秒）。
- 每个桥段结束：对照桥段四章结构复盘一次比例是否失衡。
- 每个单元结束：回 [大纲排布模板](../02-构思/大纲排布模板.md) 填实际章数与偏差原因。
- 每 10 万字：回看张弛曲线和 2:1 配比，必要时调整后续单元排序（100 万字后尤其如此）。
