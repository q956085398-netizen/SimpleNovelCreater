# 开头设计清单

> 提炼自《一本书是如何诞生的？》「开头」「开篇」两节（[原帖](../资料-原帖/一本书是如何诞生的？完整思路大公开.md)）。开头是最难写的部分——原帖作者构思了 4 个版本才定稿。本清单前六项是他给自己定的硬要求，后两部分是流程与教训。

## 六项硬要求（逐项检查）

- [ ] **1. 提前亮 boss**：开头的章节里，把全书终局 boss 和第一卷 boss（前八九十万字的对手）都写出来给读者看到——目标感更好，主线更清晰。
- [ ] **2. 开头加一个美女**：学香蕉大大的方法。（具体功能见下方「开篇第一章」的推导。）
- [ ] **3. 主角弱人设反差**：把主角开局写成懦弱无能——穿越后有反差，且周边人都认定他懦弱，制造信息差期待。
- [ ] **4. 少量打斗定题材**：权谋为主的玄幻，开头也要有一点打斗戏——不多，但必须有，体现「这是有修行者的世界」，防读者定位不准。
- [ ] **5. 节奏要快**：正常 20 章一个剧情，前 10 万字内压到 10 章一个剧情。
- [ ] **6. 钩子拉满**：尽可能多、尽可能早地放期待。参考清单——
  - 主角弱人设（反差期待）
  - 开头的美女（情感/武力期待）
  - 金手指本身（穿越游戏、掌握情报……）
  - 血压反派（短剧套路：让读者血压升高、持续蹦跶的敌人）
  - 扔在敌营的旧恋人（相认爽的远期钩子）
  - 开局即危机（紧张刺激，主角立刻有事做）

## 流程要求

- [ ] 构思**多个版本**（原帖：4 版），每版差异要大，反复权衡后选定。
- [ ] 选定后主动做**毒点评估**（见下）。
- [ ] 给编辑/写作伙伴讲一遍，**主动问「哪里让你不爽」**。

## 毒点评估（血压流教训）

原帖作者用短剧的血压流开头（太后反派持续蹦跶），主编开书前就提醒过毒点，作者权衡后明知故犯。事实证明确实毒倒了一部分读者，但他不后悔，依据是两条原则：

1. **毒点与亮点是一体两面**——完全没有毒点的书往往毫无亮点；
2. **最火的书也只能让一小撮读者喜欢**——不必奢求抓住所有人。

所以评估动作是：列出这个开头会劝退谁、留住谁、换来什么亮点，然后**明确写下「我接受这个代价」**（登记进 [构思自查清单](../02-构思/构思自查清单.md) 的风险确认单），而不是懵着头开书。

## 开篇第一章（睁眼流的操作细节）

最稳妥的开局 = **睁眼流**：主角睁眼发现穿越 → 打量环境 → 配角冲入 → 切入事件。经典意味着稳妥，别在这里炫技。

**冲进来的第一个配角怎么选（选项收敛法）：**

1. 物理列举这个场景能出现的人（政变逃杀开局 → 只有侍卫/宫女/太监）；
2. 按功能需求筛：需要前期武力保障 + 用武力展示玄幻定位 → 护卫最优；
3. 人设「合三为一」补厚：黑衣女子（《仙子请听我解释》：强大话少呆萌）+ 五竹（《庆余年》：黑衣寡言护卫）+ 温冉（《完蛋！我被美女包围了2》：黑衣女刺客）→ 开篇女护卫。

**红线：人设一致性。** 原帖事故：五六章时为趣味给高冷女护卫加「爱脑补」，被编辑指出前后不一，及时改回。教训两条：

- 人设负面清单（这个角色不会做的事）在 [人物小传](../02-构思/人物小传模板.md) 里维护；
- 开头几章最好有编辑或老读者帮看一遍。
