## 引用约定

各模块文档中凡标注「出处：原帖·篇名」的内容，均可在本文件夹找到完整上下文。
提炼后的方法论与模板都在上层目录，**日常使用不需要翻这里的原文**，它们只服务于两个场景：

1. 检验某个模板条目是不是偏离了原意（对照原文）；
2. 从原作者的推演过程里找灵感（原文比模板更有血肉）。
