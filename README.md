# SimpleNovelCreater 简单写小说

用工程化思维写小说 / 拆小说的**个人创作系统**：一个可长期维护、升级、修改的项目。
包含两部分：**本地写作台软件**（`app/`，浏览器界面 + 本地文件存储）和**方法论文库**（三大板块模板与原帖存档）。
方法来自两篇龙空精华帖（见 [资料-原帖](资料-原帖/README.md)），提炼为模板 + 工作流 + 示例。

## 本地写作台（软件，推荐入口）

** requirements**：装有 [Node.js](https://nodejs.org)（v18+）即可，无任何其他依赖。

**启动**：双击 [`app/启动.bat`](app/启动.bat)（或在 `app/` 目录运行 `node server.js`），浏览器会自动打开 `http://localhost:3746`。

| 模块 | 对应方法论 | 做什么 |
| --- | --- | --- |
| 📚 书架 | — | 多本书管理；数据存 `作品/书名/`（章节为 .md 文件 + project.json），可用 git/网盘备份 |
| 素材 | 拆书取材 | 随手收集桥段/人设/台词/设定，打标签、搜索，一键转为剧情矛盾 |
| 人物 | 人物小传 | 按阵营分组的人物卡：欲望/恐惧（剧情引擎）、秘密（情节炸药）、一致性红线（防写崩） |
| 关系 | 人物关系册+canvas | 可拖拽的关系图：连线建关系、敌对红色实线/秘密紫色虚线，关系清单直接编辑 |
| 矛盾 | 剧情矛盾清单 | 头脑风暴登记表（收人/杀人/副本/陷害），一键排入大纲 |
| 大纲 | 大纲排布模板 | 拖动排序的单元卡片，**实时检查 2:1 配比与张弛交替** |
| 写作 | 桥段四章结构 | 稿纸风编辑器 + 每章桥段角色提示（代入/拉期待/兑现/承上启下），自动保存、字数与今日码字统计 |
| 导出 | 发稿前自查 | 按起点等平台习惯排版（段首缩进/段间空行/标题格式），导出 TXT/Markdown 或直接复制单章 |

写完的书在 `作品/书名/导出/` 生成发布用全集文件；`作品/` 已被 .gitignore 排除，不会误传到 GitHub。

## 快速开始（文库部分）

1. 通读 [00-方法论/创作流程总纲](00-方法论/创作流程总纲.md)（10 分钟搞懂全流程），术语不确定就查 [核心概念速查](00-方法论/核心概念速查.md)。
2. 想拆一本书 → 从 [01-拆书/拆书工作流](01-拆书/拆书工作流.md) 开始。
3. 想开一本新书 → 从 [02-构思/构思工作流](02-构思/构思工作流.md) 开始。
4. 已在连载 → 用 [03-写作/桥段四章结构](03-写作/桥段四章结构.md) 循环生产，每章过一遍 [发稿前自查清单](03-写作/发稿前自查清单.md)。

## 目录结构

```
SimpleNovelCreater/
├── app/                      # ★ 本地写作台软件（零依赖 Node）
│   ├── server.js             #   本地服务器 + 文件存储 API（端口 3746）
│   ├── 启动.bat              #   Windows 双击启动
│   └── public/               #   前端界面（墨与纸风格，无框架）
├── 00-方法论/                # 全项目中枢：流程 + 术语
│   ├── 创作流程总纲.md        #   创意→打磨→遐想→取材→人设→大纲→开头→连载 全景流水线
│   └── 核心概念速查.md        #   单元/桥段/矛盾、爽点类型/解法、毒点、约束反推……
├── 01-拆书/                  # 板块一：拆书（灵感与解法的弹药库）
│   ├── 拆书工作流.md          #   拆什么、拆到什么颗粒度、怎么归档
│   ├── 拆书模板.md            #   逐章拆解 + 全书提炼的标准格式
│   ├── 拆书示例-护送未亡人.md  #   按模板整理的第一份实战拆书笔记
│   └── 拆书登记表.md          #   拆过什么、待拆什么
├── 02-构思/                  # 板块二：构思（从创意到可动笔）
│   ├── 构思工作流.md          #   ①创意→⑨开篇 九步流程与自检门槛
│   ├── 创意卡模板.md          #   灵感捕捉 + 约束反推 + 变形轨迹
│   ├── 爽点类型库.md          #   ★类型→解法→参考作品，只增不删的活水文件
│   ├── 人物小传模板.md        #   小传 + 合三为一取材法
│   ├── 人物关系册.md          #   阵营分组 + 关系登记（原帖的纸笔关系网）
│   ├── 组织设定模板.md        #   组织卡：结构/内部矛盾/与主角的关系曲线
│   ├── 剧情矛盾清单模板.md    #   头脑风暴登记，几十条矛盾 = 一本书的弹药
│   ├── 大纲排布模板.md        #   2:1 配比 / 张弛 / 养书 / 地图分配 四大检查
│   ├── 构思自查清单.md        #   动笔前最后一道关 + 风险确认单
│   └── canvas/
│       ├── 人物关系图模板.canvas      # 阵营分组 + 关系连线（Obsidian Canvas）
│       ├── 组织架构图模板.canvas      # 层级 + 派系裂痕 + 主角渗透线
│       └── 大纲结构图模板.canvas      # 单元时间轴，类型着色一眼查节奏
├── 03-写作/                  # 板块三：写作（连载期日常）
│   ├── 桥段四章结构.md        #   ★代入→拉期待→兑现→承上启下（生产核心）
│   ├── 开头设计清单.md        #   六项硬要求 + 血压流毒点评估 + 睁眼流操作
│   └── 发稿前自查清单.md      #   每章 60 秒：活人气 / 一致性 / 结构
└── 资料-原帖/                # 方法论原始出处（保持原样存档）
```

标 ★ 的两个入口建议常驻：**本地写作台**（日常写作）与**爽点类型库**（构思取材）。

> 写作台界面上每个模块的顶部都引用了对应方法论文档的核心原则（如人物页的「欲望与恐惧=剧情引擎」、写作页的桥段提示），方法论与软件互为表里。

## 三大板块的关系

```
01-拆书 ──供给解法/人设原型──→  02-构思 ──产出大纲/人设──→  03-写作 ──实际章节──→ 连载
   ↑                              │                          │
   └────── 拆自己写的章节复盘 ←───┴──── 反馈调整（100万字后大纲允许改）←──┘
```

拆书不在主线上，但它是构思三个环节的弹药库；写作的产出也可以回头拆（自己拆自己，最狠的进步方式）。

## 使用约定

- 模板文件**复制后使用**，原件不动；
- 本仓库只放结构化内容与模板，正文草稿、截图附件放各自的 Obsidian 库；
- 所有模板都可按需改——改完如果更好用，回头更新模板本身（这就是「可长期维护、升级、修改」的意思）。
