# SimpleNovelCreater 简单写小说

用工程化思维写小说 / 拆小说的**个人创作系统**：一个可长期维护、升级、修改的项目。
方法论来自两篇龙空精华帖（见 [资料-原帖](资料-原帖/README.md)），本仓库把其中的经验提炼成**模板 + 工作流 + 示例**，配合 Obsidian（Markdown + 双链 + canvas）使用。

## 快速开始

1. 通读 [00-方法论/创作流程总纲](00-方法论/创作流程总纲.md)（10 分钟搞懂全流程），术语不确定就查 [核心概念速查](00-方法论/核心概念速查.md)。
2. 想拆一本书 → 从 [01-拆书/拆书工作流](01-拆书/拆书工作流.md) 开始。
3. 想开一本新书 → 从 [02-构思/构思工作流](02-构思/构思工作流.md) 开始。
4. 已在连载 → 用 [03-写作/桥段四章结构](03-写作/桥段四章结构.md) 循环生产，每章过一遍 [发稿前自查清单](03-写作/发稿前自查清单.md)。

标 ★ 的两个文件建议常驻打开：**爽点类型库**（构思取材）与**桥段四章结构**（日常生产）。

## 三大板块的关系

```
01-拆书 ──供给解法/人设原型──→  02-构思 ──产出大纲/人设──→  03-写作 ──实际章节──→ 连载
   ↑                              │                          │
   └────── 拆自己写的章节复盘 ←───┴──── 反馈调整（100万字后大纲允许改）←──┘
```

拆书不在主线上，但它是构思三个环节的弹药库；写作的产出也可以回头拆（自己拆自己，最狠的进步方式）。

## 使用约定

- 模板文件**复制后使用**，原件不动；
- 本仓库只放结构化内容与模板，正文草稿、截图附件放各自的 Obsidian 库；
- 所有模板都可按需改——改完如果更好用，回头更新模板本身（这就是「可长期维护、升级、修改」的意思）。
