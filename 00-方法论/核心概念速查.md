# 核心概念速查

> 全项目共用的术语表。定义全部从两篇原帖提炼，附出处。讨论、写笔记、填模板时统一用词，避免自造同义词造成混乱。

## 结构单位

| 概念 | 定义 | 量化 | 出处 |
| --- | --- | --- | --- |
| **单元** | 一本书下的结构层：一个结构完整、节奏恰当的故事 | 6~8 万字；300 万字 ≈ 40~50 个单元 | 工程化帖 |
| **桥段** | 单元下的结构层：一次完整的「期待→兑现」循环 | 1 万多字 ≈ 4 章；全书共 200~300 个 | 工程化帖 |
| **剧情矛盾** | 构思期头脑风暴出的最小剧情包：一对待解决的冲突（该收的人、该杀的人、该过的副本） | ≈ 20 章（副本 20~40 章） | 诞生帖 |
| **章** | 桥段的功能切分单位 | 每桥段约 4 章，见桥段四章结构 | 工程化帖 |
| **千字** | 章内再往下一级的分配单位（上半/下半按功能划分） | 第一章代入:信息差 = 5:5；第二章拉扯:开装 = 9:1 | 工程化帖 |

## 期待机制

| 概念 | 定义 | 出处 |
| --- | --- | --- |
| **代入** | 让读者从熟悉内容进入新剧情的处理，最常用日常场景（起床、吃饭、路上聊天） | 工程化帖（借教育学「N+1 原则」：新内容必须搭在熟悉内容上） |
| **信息差** | 读者知道、书中人物不知道的落差；制造期待最常用的手段 | 两帖通用 |
| **期待 / 钩子** | 让读者愿意点开下一章的东西。钩子要「尽可能多、尽可能早地放」 | 诞生帖（开头六要求之一） |
| **兑现** | 把读者期待了两章的内容写透、装到位；兑现章不留新钩子 | 工程化帖 |
| **养书** | 读者攒章不追的行为。剧情关联性强（两段剧情同属一个事件）时读者更愿意一口气看完 | 诞生帖 |
| **爽点** | 读者看到书名、简介、开头后脑海中遐想、渴望看到的那些内容 | 工程化帖 |

## 爽点体系（本项目最重要的概念组）

| 概念 | 定义 | 出处 |
| --- | --- | --- |
| **类型** | 爽点的**内容分类**：读者想看的某一类东西（如「情报装逼」「掉马甲」）。一个创意通常含 4~6 种类型 | 工程化帖 |
| **解法** | 同一类型下的**不同花样**：同样用情报装逼，在哪里装、对谁装、怎么装。类型限定圈的范围，解法提供圈内的多样性 | 工程化帖 |
| **画圈** | 用爽点类型清单限定全书内容边界，**只在圈内，不在圈外**，防止写偏 | 工程化帖 |
| **爽点类型库** | 本项目对「类型→解法→参考作品」的长期积累，见 [02-构思/爽点类型库](../02-构思/爽点类型库.md) | 本项目 |

## 创作路径（三种，原帖只讲第三种）

| 概念 | 定义 | 出处 |
| --- | --- | --- |
| **填格子** | 找一本书，保留大纲、节奏、骨架，用自己的内容填充血肉 | 诞生帖 |
| **八股** | 收集同题材热门作品，总结共性、提取共性、沿袭共性、打乱重排 | 诞生帖 |
| **原创推演** | 从一个创意出发，经约束反推、读者遐想、取材、人设，一步步推演出一本书（本项目流水线对应的方法） | 诞生帖 |

## 创作手法

| 概念 | 定义 | 出处 |
| --- | --- | --- |
| **约束反推** | 不直接想「要什么」，先列全「不要什么」（读者不喜欢的、我不擅长的），剩下的唯一解往往就是正确答案 | 诞生帖（打磨环节的方法内核） |
| **合三为一** | 人设取材法：把两三个印象深刻的原型揉成一个新人物（案例：黑衣女子 + 五竹 + 温冉 → 开篇女护卫） | 诞生帖 |
| **选项收敛** | 场景里「能出现的人物」先物理列举（侍卫/宫女/太监……），再按功能需求筛选（要武力展示 → 护卫最优） | 诞生帖（开篇配角的推导过程） |
| **睁眼流** | 最稳妥的经典开局：主角睁眼发现穿越 → 打量环境 → 配角冲入引领切入事件。经典 = 稳妥 | 诞生帖 |
| **张弛交替** | 紧绷刺激的剧情与舒缓的剧情必须轮换，连续单一节奏会疲劳/无聊 | 诞生帖 |
| **升级:战斗 2:1** | 连续四五十章成长/收人剧情后，安排 20 来章打击敌人剧情 | 诞生帖（学自辰东） |
| **掉马甲** | 隐藏身份的主角被（部分）揭示身份的高爽感桥段；含「在故人面前相认」「杀反派前揭晓」等固定变体 | 诞生帖 |
| **修罗场** | 多个被攻略的女角色针对主角产生的争风吃醋场面 | 诞生帖 |
| **文抄** | 架空世界主角引用「后世」作品获得才艺震惊的桥段 | 诞生帖 |
| **爆种** | 主角遇到无法解决的难题时，付出高昂代价换取力量逆转局面的桥段（案例：人形鬼橱/神女兑换） | 诞生帖 |

## 风险与底线

| 概念 | 定义 | 出处 |
| --- | --- | --- |
| **毒点** | 让部分读者弃书的内容。**毒点与亮点一体两面**，不追求无毒点，只评估「毒换来的亮点值不值」 | 诞生帖 |
| **血压流** | 用让读者血压升高的反派拉情绪的开头套路；风险：反派不能快速被干掉，部分读者会非常不爽 | 诞生帖（短剧套路借鉴 + 主编提醒的案例） |
| **人设一致性** | 人物性格前后必须统一；为趣味临时加设定（如给高冷角色加「爱脑补」）是硬伤，需要外部审稿人把关 | 诞生帖（编辑拦下脑补设定的案例） |
| **AI 白开水** | 拆书笔记中的观察：主角无心理活动、行文平白如水、按「任务→奖励」机械推进。对策：给主角补内心戏、欲望和忐忑 | 拆书例子 |
| **筛选读者桥段** | 会劝退一部分读者、但强化另一部分读者黏性的内容（如尺度较大的情节）。写之前想清楚它筛掉谁、留下谁，订阅会受累 | 拆书例子 |
| **主角可以不强，但不能没志气** | 拆书笔记中的人设底线：主角可以弱，但必须正视自己的欲望、有向上的心气，否则显得像小丑 | 拆书例子 |
