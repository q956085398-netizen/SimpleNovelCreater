# 组织设定模板

> README 规划的「组织模块」。组织不是背景板，是**剧情的批量生产者**：它提供大人物（逼格）、提供系统性反派（长期冲突）、提供靠山（爽点杠杆）。每个重要组织一份卡。

```markdown
# 组织卡：（名称）

## 定位

- 一句话定位：（原帖案例：「类似锦衣卫的特务机构」「敌国朝廷」）
- 在故事中的功能：（批量提供对手？主角的靠山？情报来源？中期 boss 容器？）

## 结构（画进 canvas/组织架构图模板.canvas）

| 层级 | 人物/职位 | 与主角的关系 |

| 顶层 |  | （终局对手/暗中靠山……） |
| 中层 |  | （日常冲突的来源/可策反对象） |
| 外围/爪牙 |  | （前期对手戏） |

## 实力与资源

- 硬实力：
- 情报/人脉/特殊资源：
- （自洽检查：拆书笔记教训——「沈家实力没处理好导致读者质疑」。
  组织实力的每一次展示要与前面铺垫对账。）
```

## 设计提示

1. **先想功能再想名号**：组织存在的理由是剧情需要它生产什么，不是它听起来多酷。
2. **至少两个派系**：铁板一块的组织没法被架空，也没法写内部戏。
3. **实力展示留底**：每次写组织出手，记一笔——读者记得住前后矛盾，尤其是战斗力。
4. 组织与人物联动：组织卡里的每个「人物/职位」格子，重要者建 [人物小传](人物小传模板.md)。
