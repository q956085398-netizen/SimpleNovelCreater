# 爽点类型库

> 本项目最重要的活水文件。**只增不删**：拆书拆到的解法、追更时看到的妙招，随手登记进来；构思时按类型取用。
>
> - **类型** = 读者想看的一类内容（圈的范围）
> - **解法** = 同一类型的不同花样（圈内的多样性）
> - 出自原帖的定义见 [核心概念速查](../00-方法论/核心概念速查.md)

## 使用方式

1. **构思期（遐想阶段）**：从下面挑出你这个创意的 4~6 种类型 = 这本书的「圈」，在「我的书」列登记你的用法规划。
2. **拆书时**：看到好的解法 → 找到对应类型 → 登记一行（注明出处章节）。
3. **写作卡壳时**：当前桥段属于哪个类型 → 来库里换一种没用过的解法。
4. 长期自检：某类型的解法数长期 ≤ 2，说明这块储备贫瘠，优先拆相关作品补货。
