# 构思自查清单

> 动笔前最后一道关。逐项打钩，未通过的项目要么补课、要么明确接受风险（写下来）。检查项全部提炼自原帖的教训与做法。

## A. 创意与故事雏形

- [ ] 我能用三句话讲清「主角是谁、核心冲突是什么、故事发生在哪」。
- [ ] 真正吸引我的核心已经剥离（不是题材外壳，是那个让我兴奋的处境）。
- [ ] 约束清单列全了：读者不喜欢的 + 我不擅长的，且故事雏形是反推出来的唯一解。
- [ ] 讲给一个懂网文的朋友听过，他有追问「然后呢」。

## B. 爽点画圈

- [ ] 以读者视角完成了遐想，列出约 10 条想看的内容。
- [ ] 归并成 4~6 种类型，每种类型我都能随口说出 2~3 种解法。
- [ ] 类型已在 [爽点类型库](爽点类型库.md) 登记，解法储备到位（缺口已安排拆书补货）。
- [ ] 我明白这本书的「圈」是什么：圈外的内容再兴奋也不写。

## C. 人设与世界观

- [ ] 故事会出现的重要人物都有小传：生平、欲望与恐惧、秘密。
- [ ] 人物关系册已建：敌对/师徒/亲戚/私情/秘密……
- [ ] 任意两个重要人物之间说得出一条关系；说不出的删人或加线。
- [ ] 每条关系我都想过「它能生产什么剧情」。
- [ ] 不擅长的设定（力量体系/地图）已做简——刻意淡化，不硬撑。
- [ ] 每个人物有「不会做的事」负面清单（防 OOC、防临时加趣味设定）。

## D. 剧情矛盾

- [ ] 矛盾登记 ≥ 几十条（≈ 几百万字的弹药）。
- [ ] 每条矛盾至少动一条人物关系。
- [ ] 类型分布确认：收人类与杀人类都有足够数量（支撑 2:1）。

## E. 大纲

- [ ] 升级:战斗 ≈ 2:1，无连续 3 个以上同型单元。
- [ ] 张弛交替，无连续 3 个同氛围单元。
- [ ] 至少一半相邻单元有养书关联设计。
- [ ] 地图分配合理，主场地图承载主线。
- [ ] 终局 boss 与第一卷 boss 会在开头章节亮出。

## F. 开头

- [ ] 过了 [开头设计清单](../03-写作/开头设计清单.md) 六项要求。
- [ ] 构思了不止一个版本，做过权衡（原帖作者写了 4 版）。
- [ ] 开头方案的毒点已识别，且我明确接受它的代价（血压流教训：主编提醒过，作者是明知故犯并认账）。
- [ ] 开篇第一章的切入配角已用「选项收敛法」推导，人设可用「合三为一」补厚。

## G. 风险确认单（可选但推荐）

> 这几条不是必过项，是「明知故犯登记处」——原帖作者多次明知代价仍做选择，关键是**知道代价再选**。

| 例：淡化修炼体系 | 设定党流失 | ☐ |
