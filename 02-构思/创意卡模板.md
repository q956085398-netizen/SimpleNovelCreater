# 创意卡模板

> 一张卡 = 一个创意。创意在没走完「打磨」之前都只值一行字，卡片的作用是让它不蒸发，并记录推演的变形轨迹。复制本文件使用。

```markdown
# 创意卡：《暂定名 / 编号》

- 记录日期：
- 状态：孵化中 / 已立项 → （立项后把链接贴到这里）

## 一句话创意

（为什么它让你兴奋？哪个瞬间你脑子里「咔」了一下？）

## 灵感来源

（游戏背景 / 史料 / 影视 / 梦境 / 某本书写砸了的题材……贴链接或截图）

## 剥离：真正吸引我的核心

（原帖案例：吸引他的不是「家族诅咒」，而是「从逃难中聚集星星之火反攻」。
问自己：如果这个创意只保留一个画面/一个处境，我保留哪个？）

## 约束清单（打磨用）

### 读者不喜欢的
- （换地图 / 前期人物逼格不够 / 带兵打仗 / ……按你的题材补全）

### 我不擅长的
- （家族文 / 修炼升级 / 设定流 / 感情戏 / ……诚实一点）

### 反推：约束之后剩下的解

（原帖案例：不换地图+大人物+不打仗 → 主角不能离开京城 → 宫廷政变 → 谍战+掉马甲）

## 题材判断

- 男频/女频、题材标签：
- 这个题材里已有的头部作品与它们提供的读者预期：
- 我的差异化：

## 下一步

- [ ] 立项：进入 [构思工作流](构思工作流.md) ③读者遐想
- [ ] 或者：搁置（写在待办里，创意不丢）
```
