# 人物小传模板

> 给每个重要人物建一份。人设即世界观（原帖）。填完把人物登记进 [人物关系册](人物关系册.md)，关系画进 `canvas/人物关系图模板.canvas`。

```markdown
# 人物小传：（姓名）

## 基本盘

- 身份 / 阵营：
- 形象参考图：（Obsidian 附件贴这里；来源：影视剧照/切片，只自己用）
- 一句话人设：（原帖案例：「强大、话不多、有些呆萌」）

## 生平经历

（3~5 段。他如何变成今天这个人——经历决定行为逻辑。）

## 欲望与恐惧

- 他最想要：
- 他最怕：
- （剧情引擎：把他想要的放在主角对立面/合作面上，把他怕的做成把柄）

## 秘密

- 他藏着的：（秘密 = 情节炸药。主角的金手指若与情报相关，这里是主战场）
- 谁还知道：

## 能力 / 与金手指的关系

- （武力/智力/资源；主角对他可用的杠杆是什么）

## 与主线的关系

- 功能定位：（提供前期武力 / 靠山 / 反派 / 待收服对象 / 情报源 / 感情线……）
- 出场计划：（预计在第几个单元登场；退场方式）

## 人物弧光

- 开场状态 → 结束状态：
- （可选项：不是人人需要弧光，功能型角色可以不变）

## 一致性红线

- 这个角色**不会**做的事：（写作时防 OOC 的负面清单；
  教训出处：原帖——给高冷护卫加「爱脑补」被编辑打回）
```

## 合三为一取材法

原帖的人设生成方式，值得作为默认操作：把两三个印象深刻的原型揉成一个。

> 案例：开篇女护卫 =《仙子请听我解释》黑衣女子（强大话少呆萌）+《庆余年》五竹（黑衣护卫寡言）+《完蛋！我被美女包围了2》温冉（黑衣女刺客）。

操作：

1. 写下让你印象深刻的角色 2~3 个，各标注「吸引我的那一个特质」；
2. 只取特质，不取情节；
3. 揉合后检查：拼出来的还是不是一个人？（特质之间要能共存）
