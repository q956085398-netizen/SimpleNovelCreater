# 人物关系册

> 原帖作者用纸质笔记本画关系网（阵营分组 + 名字连线）；本项目用「关系册（本文件）+ canvas 图」替代纸笔，作用相同：**让人物之间有更强的关联，而人物意味着一个又一个的剧情——关系越密，铺垫越自然，新剧情出现时读者不觉得突兀，反而产生期待。**

## 使用方法

1. 每本书开一个二级标题区。
2. 按阵营列人物（与 canvas 图一致）。
3. 关系登记成对记录：`A —关系— B（说明/伏笔）`。
4. 与 canvas 同步：图管「看」（整体密度一眼可见），册管「查」（检索与细节）。
5. 每次剧情矛盾立项时回来检查：这条矛盾动了哪些关系？要不要新增关系？

## 关系类型词汇表

> 关系类型 = 剧情类型的索引。新增关系类型时先问：这种关系能生产什么剧情？

| 关系 | 能生产的剧情 |
| --- | --- |
| 敌对 | 打击/陷害/报复 |
| 师徒 | 传承/背叛/考验 |
| 亲戚 | 联姻/夺产/庇护 |
| 私情（不为人知） | 暴露危机/把柄/修罗场 |
| 秘密（共同或单向） | 拿捏/灭口/互换筹码 |
| 恩情 | 报恩/道德绑架/人情链 |
| 依附 | 站队/抛弃/反向掌控 |
| 旧识（断裂的） | 掉马甲相认/隔阂消解 |

（前六种出自原帖画关系网时的原文举例，后两种为项目补充——欢迎追加。）

## 示例区：《架空历史权谋》（结构示例，原帖设定摘编）

### 阵营：主角方（旧朝余脉）

- 主角（潜伏的前朝皇帝，改容以谋士身份入新朝）
- 开篇女护卫（唯一识破主角身份的近侍｜关系：依附+秘密）
- 流散的旧臣（待营救/待收服对象）

### 阵营：新朝

- 新帝一方：太子
- 皇子一方：纨绔皇子、其姐聪明腹黑的公主（关系：姐弟；主角的切入点）
- 类锦衣卫机构头子（关系：与主角互为猎物）
- 太后（开局反派/血压钩子）

### 关系登记

- 主角 —秘密— 女护卫（她知道我是谁｜伏笔：忠诚的建立）
- 主角 —依附→ 公主（借皇子集团立足｜伏笔：反客为主）
- 公主 —敌对— 太子（结构化斗争｜出《庆余年》式权谋线）
- 主角 —旧识— 被囚旧臣（营救戏的相认爽点）

### 密度自检

- 上面 9 个人物 4 条关系，密度偏低——原帖作者的下本书目标是「花更多精力做仔细」。
- 检查口诀：任意两人之间说得出一条关系吗？说不出 → 删一人或加一线。
