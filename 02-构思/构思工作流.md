# 构思工作流

> 从一个创意到可以动笔的完整流程，提炼自《一本书是如何诞生的？完整思路大公开》（[原帖](../资料-原帖/一本书是如何诞生的？完整思路大公开.md)）。
> 每一步链接对应模板；「自检」是进入下一步的门槛。

```
① 创意 → ② 打磨 → ③ 遐想 → ④ 取材 → ⑤ 人设 ┬→ ⑦ 大纲 → ⑧ 开头 → ⑨ 开篇
                                    ⑥ 剧情矛盾 ┘
```

## ① 创意

捕捉让你**兴奋、有想象空间**的碎片。来源不限：游戏背景、史料、影视桥段、别人写烂了你觉得能救的题材。

- 动作：登记 [创意卡](创意卡模板.md)。此时只有「这个让我兴奋」，其余都是空的。
- 自检：过两天再看你还会不会兴奋。不兴奋的创意不值得花后面的功夫。

## ② 打磨（约束反推）

- 动作：
  1. 把创意里**真正吸引你的核心**剥离出来（原帖案例：真正吸引他的不是家族，而是「从逃难中聚集星星之火反攻」）；
  2. 列两个清单：**读者不喜欢的**（换地图、前期人物逼格不够、带兵打仗……）、**我不擅长的**（家族文、修炼升级、设定流……）；
  3. 用排除法反推：主角不能离开京城 → 宫廷政变 → 谍战+掉马甲。
- 关键心态：允许创意变形。推演到变形后你更兴奋了，说明方向对。
- 自检：能用三句话讲清「主角是谁、核心冲突是什么、故事发生在哪」。讲故事雏形给一个懂网文的朋友听，看他有没有追问「然后呢」。

## ③ 读者遐想（爽点画圈）——整个构思里最值钱的一步

- 动作：**只带读者视角**问：「如果我看到这个故事，我最想看什么？」原帖作者花了三天只想这一个问题。把答案列成 10 条左右，归并成 4~6 种**爽点类型**。
- 产出：这本书的「圈」。全书内容**只在圈内，不在圈外**——圈防写偏，圈内解法的多样性防疲劳。
- 动作续：每种类型去 [爽点类型库](爽点类型库.md) 领解法；库里没有的类型，新建区并开始收集解法。
- 自检：随便挑一条类型，你能立刻说出两三种不同的解法吗？说不出来，说明这条类型你自己都没想看，删掉或补课。

## ④ 按类型取材

- 动作：**每条类型**找 2~3 部处理过同样元素的代表作（小说、剧、影游皆可）。看的是**解法与人设**，不是情节。
- 原帖案例：写驾驭下属看《万历明君》《绍宋》；写谍战看《潜伏》；写黑衣护卫人设看《仙子请听我解释》《庆余年》《完蛋！我被美女包围了2》。
- 两个随身动作：
  - 灵感来了立刻记进 [剧情矛盾清单](剧情矛盾清单模板.md)——剧情矛盾不是单独一个阶段憋出来的，是取材时头脑风暴的副产品；
  - 有感觉的形象截图存档——这是人设的原型素材。

## ⑤ 人设 / 世界观

- 动作：
  1. 列出故事会出现的重要人物（敌我大人物、宫廷角色、类似锦衣卫的头子……）；
  2. 每人一份 [人物小传](人物小传模板.md)（生平经历 + 形象参考图）；
  3. 按阵营分组，在 [人物关系册](人物关系册.md) 里连线：敌对 / 师徒 / 亲戚 / 私情 / 秘密……关系网同时画进 canvas（`canvas/人物关系图模板.canvas`）；
  4. 势力与组织做 [组织设定](组织设定模板.md)。
- 三条铁律（出处：原帖）：
  - **人设即世界观**：做人设的过程就是做世界观的过程；
  - **每条关系都是一条潜在剧情**：关系越密，剧情间铺垫越自然，读者不会觉得新剧情突兀；
  - **不擅长的设定做简**：力量体系、地图，题材不需要就一笔带过（作者自己这两块就「做的非常的简略」）。
- 自检：任意两个重要人物之间，说得出一条关系吗？说不出的两个人，考虑删掉一个或建立关系。
- 警示：这部分是作者自认「做起来不开心所以准备不够」的环节——下本书要花更多精力。canvas 和关系册就是为了把它变得不那么痛苦。

## ⑥ 剧情矛盾清单

- 动作：整理取材期间的头脑风暴产物。每条矛盾 = 一对冲突（该收的人 / 该杀的人 / 该过的副本事件），登记进 [剧情矛盾清单](剧情矛盾清单模板.md)。
- 数量自检：**几十条**才算撑起一本书（每条 ≈ 20 章，几十条 × 20 章 ≈ 几百万字）。不够就回④继续取材、继续风暴。

## ⑦ 大纲排布

- 动作：把矛盾单元串成线，见 [大纲排布模板](大纲排布模板.md)。反复检查三件事 + 地图分配：
  - 升级:战斗 ≈ 2:1（四五十章收人 + 二十来章杀人）；
  - 张弛交替；
  - 相邻剧情的关联性（养书设计）；
  - 地图：京城 / 地方 / 敌国 / 世界边缘的分布。
- 产出：大纲排布表 + `canvas/大纲结构图模板.canvas` 的结构图。
- 心态：这块「涉及大量直觉和经验」，很难完全说清——模板检查表就是把直觉外化成可核对项。
- 有效期：**前 100 万字严格执行；之后允许随创作调整、删减、增补。**

## ⑧ 开头设计

- 动作：过 [开头设计清单](../03-写作/开头设计清单.md)（六项要求 + 钩子清单 + 毒点评估）。构思多个版本反复权衡（原帖作者写了 4 版）。
- 自检：把你设计的开头讲给编辑或写作伙伴听，**主动问「哪里让你不爽」**——原帖教训：血压流开头的毒点，主编开书前就提醒过，作者明知故犯并接受了代价。你也可以明知故犯，但要先知道代价。

## ⑨ 开篇第一章

- 动作：
  1. 选最稳的开局模式（睁眼流——经典 = 稳妥）；
  2. 「选项收敛」推导冲进来的第一个配角：这个场景里物理上能出现谁（侍卫/宫女/太监）→ 按功能需求筛（要武力保障 + 展示玄幻定位 → 护卫最优）；
  3. 用「合三为一」给配角做扎实人设（黑衣女子 + 五竹 + 温冉 → 开篇女护卫）。
- 红线：**人设一致性**。给角色临时加「趣味设定」（爱脑补）导致前后不一，是编辑都会拦下的硬伤。
- 之后：按大纲稳步推进，进入 [03-写作](../03-写作/桥段四章结构.md) 的桥段循环。

## 构思期时间参考

原帖作者的耗时分布（供参照，不是标准）：遐想 3 天；取材一段时间（大部分扫一眼）；人设耗时多且「不开心」；剧情矛盾在取材中顺手完成；大纲排布「耗费一定时间」；开头 4 个版本。
